## Prerequisites

Python 3.10+
pip

Setup
1. Clone the repository <br>
'bashgit clone https://github.com/codedsami/SOEN-321-Project.git' <br>
cd SOEN-321-Project/secure-file-sharing/backend
2. Create and activate a virtual environment <br>
'bashpython -m venv venv'
<br>
venv\Scripts\activate
<br>
3. Install dependencies <br>
'bashpip install -r requirements.txt' <br> <br>
4. Create a .env file in the backend/ folder <br>
JWT_SECRET_KEY=your-secret-key-here <br>
DATABASE_URL=sqlite:///secure_files.db <br> <br>
5. Run the app
bashpython app.py <br>
Server runs at http://127.0.0.1:5000 <br> <br>

API Endpoints <br>
POST/register <br>
