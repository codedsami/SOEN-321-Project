How key sharing works:
  1. Your private key decrypted via PBKDF2 + AES-256-GCM
  2. Your wrapped FEK unwrapped with your RSA private key
  3. Raw FEK re-wrapped with recipient's RSA public key (OAEP)
  4. New wrapped FEK stored in Shares table — server never sees the raw FEK
  5. Recipient uses their own private key to unwrap and decrypt
